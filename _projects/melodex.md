MeloDEX is an AI-powered search engine that lets users find songs by simply describing the mood or style they are looking for. It incorporates a sleek React UI, relational filtering, efficient vector search, and Spotify and Apple Music integrations.

**Key features:**
- Semantic search via vector embeddings — describe a vibe, not a title
- Relational filtering (genre, tempo, key, etc.) on top of vector results
- Spotify and Apple Music deep-link integrations
- React frontend with fast, responsive UI

**Stack:** Python, React, vector database, REST APIs
