ShopEase is a microservices-based e-commerce platform with a Spring (Java) backend that provides secure product management and order tracking via OAuth 2.0, deployed on AWS using Lambda and RDS (Postgres).

**Key features:**
- Microservices architecture with independently deployable services
- OAuth 2.0 authentication and authorization
- Product catalog, inventory, and order tracking
- Serverless deployment on AWS Lambda backed by RDS (Postgres)

**Stack:** Java, Spring Boot, OAuth 2.0, AWS Lambda, AWS RDS, Postgres
