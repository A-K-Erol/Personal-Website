A tool leveraging Retrieval-Augmented Generation (RAG) to generate organization-specific content for grant-writing, packaged as a React/Flask application and served on Google Cloud Platform. Built for [People for PSEO](https://www.peopleforpseo.org/), a Minnesota non-profit advocating for dual-enrollment students.

**Key features:**
- RAG pipeline grounded in the organization's own documents and past grants
- LLM-generated draft content tailored to specific grant requirements
- React frontend with Flask API backend
- Deployed on Google Cloud Platform

**Stack:** Python, Flask, React, LLM APIs, GCP, RAG
